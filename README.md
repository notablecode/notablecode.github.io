# notablecode.github.io

Public website for Notable Code, served by GitHub Pages.

The entire site is a single self-contained `index.html` (inline CSS and JavaScript, no build step).

Contact details are stored obfuscated in the script block and revealed only on click, and the click must come from a pointer whose recent path bends at least 2px off a straight line (touch and keyboard activation are accepted). See the comment in the script block for how to regenerate the encoded values.
